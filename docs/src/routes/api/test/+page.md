# Test Utilities

The test entry point (`@robelest/convex-embedded/test`) provides helpers for
testing embedded Convex applications with `convex-test`.

```ts
import { register } from "@robelest/convex-embedded/test";
```

---

## `register(t, name?)`

Registers the embedded component with a `convex-test` instance. This sets up the
internal component schema and modules so that embedded table mutations, queries,
and the CRDT delta storage work correctly in tests.

```ts
function register(
  t: TestConvex<SchemaDefinition<GenericSchema, boolean>>,
  name?: string,
): void;
```

| Parameter | Type                                                   | Default      | Description                                                                                                  |
| --------- | ------------------------------------------------------ | ------------ | ------------------------------------------------------------------------------------------------------------ |
| `t`       | `TestConvex<SchemaDefinition<GenericSchema, boolean>>` | **required** | The test convex instance returned by `convexTest()`.                                                         |
| `name`    | `string`                                               | `"embedded"` | Component name as registered in `convex.config.ts`. Must match the name used in your component installation. |

Internally, this calls `t.registerComponent(name, schema, modules)` with the
embedded component's schema and module map.

---

## Usage Example

```ts
import { convexTest } from "convex-test";
import { describe, it, expect } from "vitest";
import { register } from "@robelest/convex-embedded/test";
import { api } from "./convex/_generated/api";
import { modules } from "./convex-modules";
import schema from "./convex/schema";

describe("tasks", () => {
  it("should create and list tasks", async () => {
    const t = convexTest(schema, modules);
    register(t);

    // Create a task
    const taskId = await t.mutation(api.tasks.create, {
      title: "Buy groceries",
      body: "Milk, eggs, bread",
    });
    expect(taskId).toBeDefined();

    // List tasks
    const tasks = await t.query(api.tasks.list, {});
    expect(tasks).toHaveLength(1);
    expect(tasks[0].title).toBe("Buy groceries");
    expect(tasks[0].body).toBe("Milk, eggs, bread");
  });
});
```

## Complete Test File Example

A more comprehensive test file showing auth, mutations, and queries:

```ts
import { convexTest } from "convex-test";
import { describe, it, expect, beforeEach } from "vitest";
import { register } from "@robelest/convex-embedded/test";
import { api } from "./convex/_generated/api";
import { modules } from "./convex-modules";
import schema from "./convex/schema";

describe("embedded tasks", () => {
  let t: ReturnType<typeof convexTest>;

  beforeEach(() => {
    t = convexTest(schema, modules);
    register(t);
  });

  it("creates a task and retrieves it", async () => {
    const id = await t.mutation(api.tasks.create, {
      title: "Write tests",
      body: "Cover all CRDT field types",
    });

    const tasks = await t.query(api.tasks.list, {});
    expect(tasks).toHaveLength(1);
    expect(tasks[0].title).toBe("Write tests");
  });

  it("works with authenticated users", async () => {
    const asAlice = t.withIdentity({
      name: "Alice",
      subject: "alice-123",
      issuer: "https://auth.example.com",
      tokenIdentifier: "https://auth.example.com|alice-123",
    });

    const id = await asAlice.mutation(api.tasks.create, {
      title: "Alice's task",
      body: "Only Alice can see this",
    });

    const tasks = await asAlice.query(api.tasks.list, {});
    expect(tasks).toHaveLength(1);
  });

  it("handles the resolve query", async () => {
    // Create some data first
    await t.mutation(api.tasks.create, {
      title: "Sync me",
      body: "This will be resolved",
    });

    // The resolve query is auto-generated by embeddedTable
    const result = await t.query(api.tasks.resolve, {
      documents: [],
    });
    expect(result).toEqual([]);
  });
});
```

## Notes

- The `register` function must be called **after** `convexTest()` creates the
  test instance and **before** any mutations or queries that interact with
  embedded tables.
- The `name` parameter defaults to `"embedded"`, which matches the standard
  component installation name in `convex.config.ts`. If you installed the
  component under a different name, pass that name explicitly.
- The test utilities ship with their own internal lazy module registry for the
  embedded component. No Vite-specific module globbing is required.
